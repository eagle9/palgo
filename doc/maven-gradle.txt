run test with maven
==================
mvn -Dtest=org.voyiger.TestCircle test
The value for the test parameter is the name of the test class (without the extension; we'll strip off the extension if you accidentally provide one).

You may also use patterns to run a number of tests:

mvn -Dtest=TestCi*le test
And you may use multiple names/patterns, separated by commas:

mvn -Dtest=TestSquare,TestCi*le test


maven vs gradle
==============
maven use xml which gradle use groovy, so gradle is more flexible and concise
gradle use DAG model for tasks
gradle supports plugins that can build artifacts from java, c/c++, kotlin, etc. Wider range of source code projects. 
gradle uses build cache so it has faster build
maven is good for small projects. For larger and more complex projects, gradle has advantages.
