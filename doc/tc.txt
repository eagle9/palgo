tc qdisc add dev eth3 root netem delay 10ms 5ms
#This would give us random variation of 10ms +/- 5ms, uniform distribution

tc qdisc add dev eth3 root netem delay 10ms 5ms 25%
#This means the added delay is 10ms +/- 5ms with the next random element depending 25% on the last one.  Note that this is an approximation, not a true statistical correlation.

tc qdisc add dev eth3 root netem delay 10ms 5ms distribution normal
#specify non-uniform distribution (normal, pareto, paretonormal)
